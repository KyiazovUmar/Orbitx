# OrbitX

An interactive orbital mechanics simulator and Near-Earth Object (NEO) tracker built with HTML, CSS, and JavaScript.

## Features

- **Real-Time Simulation:** Accurately renders elliptical orbits for targets like the International Space Station, Hubble, and asteroid Apophis.
- **Smooth Pan & Zoom:** Custom camera matrix supporting mouse-drag panning and cursor-centered scroll zooming.
- **Procedural Earth:** Features rotating continental landmasses, Rayleigh-scattering atmospheric glow, and a day/night terminator cycle.
- **Live Telemetry & Logs:** Includes speed controls, velocity vectors, grid overlays, and a live system console.
